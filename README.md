# Job Application Tracker

A full-stack web application built with Python and Flask to organize, manage, and track job applications through a centralized dashboard.

## Features
- Add, edit, and delete job applications.
- Track application statuses.
- Store company, position, location, and application date.
- Add job posting links and personal notes.
- Search applications by company or position.
- Filter applications by status.
- Dashboard with application statistics.
- Persistent SQLite database.

## Technologies Used
- Python
- Flask
- SQLite
- HTML5
- CSS3

## Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/Job-Application-Tracker.git
cd Job-Application-Tracker
```

Create a virtual environment:

```bash
python -m venv .venv
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
